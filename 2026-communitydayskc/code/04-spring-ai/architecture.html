Spring AI

LLM-powered fraud explanation — ChatClient + Structured Output + Provider Swap

ChatClient Fluent API

Spring AI's ChatClient is a builder-style API similar to WebClient. Chain .prompt().user(...).call() for any LLM interaction with full type safety.

Structured Output

Calling .entity(FraudExplanation.class) makes Spring AI reflect on the record, generate a JSON schema, instruct the LLM, and deserialise the response — all automatically.

Provider Portability

Swap the Maven starter (OpenAI → Claude → Ollama) and update one property. Your ChatClient code never changes — the same abstraction works across all providers.

// AiConfig.java — set the system persona once, reuse everywhere @Bean ChatClient chatClient(ChatClient.Builder builder) { return builder .defaultSystem("You are a senior fraud analyst...") .build(); } // FraudExplainerService.java — parameterized prompt + structured output public FraudExplanation explain(FraudAlert alert) { return chatClient.prompt() .user(u -> u .text("Analyze TX {txId}: amount {amount}, prob {prob}%...") .param("txId", alert.transactionId()) .param("amount", alert.amount()) .param("prob", alert.fraudProbability() * 100)) .call() .entity(FraudExplanation.class); // Spring AI auto-deserialises to Java record }
