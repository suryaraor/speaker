🏗️ Model as a Service

REST Pattern: Python ML Service + Spring Boot Client

Feature Engineering in Java • Inference in Python • REST API Contract

📐 System Architecture

☕
Spring Boot Client
Java Application Layer
  • REST API Endpoints (/api/fraud/*)
  • Feature Engineering Logic
  • WebClient (Non-blocking)
  • 200ms Timeout + Fallback
  • Transaction Processing
  • Domain Knowledge
🐍
FastAPI ML Service
Python AI Layer
  • RandomForest Model (sklearn)
  • Fraud Detection Inference
  • Pydantic Validation
  • Feature Importance Scores
  • Health Monitoring
  • Model Versioning
POST /predict/fraud (JSON)

🔧 Java: Feature Engineering

Business domain knowledge stays in the Java layer. Transforms raw transactions into ML-ready features (amount, hour, merchant risk, velocity, geo risk).

🤖 Python: AI Inference

Dedicated ML layer handles predictions. RandomForest model trained on synthetic fraud patterns. Returns fraud probability, risk level, and feature importances.

⚡ Non-blocking Calls

Spring Boot uses WebClient for async HTTP calls. 200ms SLA timeout prevents blocking. Graceful fallback when ML service is unavailable.

📊 Typed Contracts

Jackson Records (Java) ↔ Pydantic Models (Python). Strong typing ensures consistency across language boundaries.

🎯 API Pattern

RESTful endpoints for easy testing, monitoring, and scaling. Health checks and metrics endpoints included.

📈 Model Versioning

ML responses include version info. Easy to track which model version made predictions for debugging and compliance.

📋 Data Models

Request: TransactionFeatures (From Java)

{ "amount": 1850.0, "hour_of_day": 3, "merchant_risk_score": 0.8, "velocity_30d": 22, "geo_risk_score": 0.75 }

Response: FraudScore (From Python)

{ "fraud_probability": 0.92, "is_fraud": true, "model_version": "v1.0.0", "risk_level": "HIGH", "feature_importances": {...} }

🔗 Java-AI Interaction Flow

1

Client Request (Java)

Spring Boot receives raw transaction. Feature Engineer extracts 5 key features from transaction object.

2

HTTP POST Request

WebClient sends TransactionFeatures as JSON to Python ML service with 200ms timeout.

3

ML Inference (Python)

FastAPI receives request, validates with Pydantic, passes to RandomForest model for prediction.

4

Return Score

Python calculates fraud probability, risk level, and feature importances. Returns FraudScore JSON.

5

Response Handling (Java)

Spring Boot receives response, maps to FraudScore Record, returns to REST client.

6

Fallback (Optional)

If Python service times out (200ms), return conservative fraud score to prevent fraud while system recovers.

⭐ Key Features

🔀

Separation of Concerns

Business logic (Java) separate from ML logic (Python). Easy to evolve each independently.

⚙️

Loose Coupling

REST API contract allows any language replacement. Could swap Python for Rust, Go, etc.

⏱️

Async Non-blocking

WebClient doesn't block threads. Efficient under load. 200ms timeout prevents system hang.

🛡️

Graceful Degradation

When ML service fails, fallback strategy ensures system continues operating safely.

📊

Model Transparency

Feature importances returned with every prediction. Explainable AI for audit/compliance.

🔍

Easy Testing

HTTP endpoints mockable. Postman collection for integration testing. Health checks for monitoring.

⏲️ Request/Response Timeline

0ms: Client Request

Spring Boot receives transaction, creates FeatureEngineer, extracts features

5-10ms: HTTP POST Sent

WebClient sends TransactionFeatures JSON to FastAPI endpoint

10-50ms: ML Inference

RandomForest processes features, generates prediction probabilities and importances

50-60ms: Response Sent

FastAPI returns FraudScore JSON with all details

60-80ms: Client Receives

Spring Boot maps response to FraudScore record, applies business logic

80-100ms: Response Ready

Fraud decision returned to REST client (well under 200ms SLA)

💻 Code Integration Pattern

// Java: Feature extraction TransactionFeatures features = featureEngineer.extract(transaction); // Call Python ML service via WebClient Mono<FraudScore> response = webClient .post() .uri("http://localhost:8000/predict/fraud") .bodyValue(features) .timeout(Duration.ofMillis(200)) .retrieve() .bodyToMono(FraudScore.class); // Handle timeout gracefully return response.onErrorReturn( new FraudScore(..., true, "FALLBACK") );
