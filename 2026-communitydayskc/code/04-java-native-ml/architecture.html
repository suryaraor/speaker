🔄 Java-Native Prediction Flow

1️⃣ Extract Features

HTTP request received. Spring Boot controller extracts 6 features from JSON: credit score, income, loan amount, employment years, debt-to-income ratio.

2️⃣ Create Instance

CreditRiskClassifier converts features to Weka Instance object. Validates all numeric ranges and types.

3️⃣ Predict

RandomForest classifies instance. Returns probability distribution: [APPROVE, DENY, REVIEW]. Picks highest probability.

4️⃣ Return Result

Decision (APPROVE/DENY/REVIEW) + all probabilities + explanation text. Sub-millisecond response time.

💻 Pure Java ML Integration

// Step 1: Build Weka Instances schema ArrayList<Attribute> attributes = new ArrayList<>(); attributes.add(new Attribute("creditScore")); attributes.add(new Attribute("annualIncome")); // ... more features // Step 2: Train RandomForest on synthetic data Instances trainingData = generateSyntheticData(attributes); RandomForest model = new RandomForest(); model.buildClassifier(trainingData); // Step 3: Predict on new application Instance newApp = new Instance(trainingData.numAttributes()); newApp.setValue(creditScore, 690); newApp.setValue(income, 65000); // ... set other features double prediction = model.classifyInstance(newApp); double[] probabilities = model.distributionForInstance(newApp); // probabilities[0] = APPROVE, [1] = DENY, [2] = REVIEW
