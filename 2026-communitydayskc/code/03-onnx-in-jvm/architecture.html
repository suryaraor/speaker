// Step 1: Load ONNX model at application startup OrtSession session = environment.createSession("fraud_model.onnx"); // Step 2: Create float array with features [amount, hour, merchant_risk, velocity, geo_risk] float[][] inputData = {{ 1850f, 3f, 0.8f, 22f, 0.75f }}; OnnxTensor input = OnnxTensor.createTensor(environment, inputData); // Step 3: Run inference (sub-millisecond!) try (OrtRunnable.Result results = session.run(Collections.singletonMap( "input", input))) { float[] probabilities = (float[]) results.get(0).getValue(); double fraudProbability = probabilities[1]; // Index 1 = fraud class return new FraudScore(fraudProbability, fraudProbability > 0.85); }

🤔 When to Use ONNX In-JVM

✅ Perfect For:
  • 🚀 Real-time trading/fraud detection
  • 📱 Mobile/edge ML (low latency)
  • 🔒 Air-gapped/regulated networks
  • 💰 Cost-optimized (no microservice overhead)
  • 🎯 Java-first organizations
  • ⚡ Batch scoring (1000s per minute)
❌ Not Ideal For:
  • ❌ Large deep learning models (size > JVM memory)
  • ❌ Frequently retraining models (10+ times/day)
  • ❌ Complex preprocessing pipelines
  • ❌ Multi-framework ensembles
  • ❌ Teams without ML expertise
  • ❌ Rapidly evolving ML code
